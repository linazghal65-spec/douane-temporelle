Douane Temporelle (Time Travel Customs)
Mini-projet Programmation Mobile (DS 1), application Android en Java avec 3 activités :

MainActivity : formulaire d'enregistrement du voyageur
VerificationActivity : scanner de paradoxe (passeport temporel)
ResultActivity : verdict (vert = approuvé, rouge = refusé)

Règles implémentées
Clés des putExtra construites par Keys.build(matricule, suffixe)
Bouton "Approuver" désactivé si motif = "Modification du passé" et différence d'années première
IDs des vues suffixés par les initiales du groupe
Code commenté en arabe
